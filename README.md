# Daolin Bai — Academic Homepage

Static academic homepage for Daolin Bai, an Economics Ph.D. candidate at The Chinese University of Hong Kong, on the 2026–2027 academic job market.

## Website

Intended GitHub Pages address: https://daolinbai0727-hub.github.io/

## Contents

- `index.html`: introduction, job market paper, working paper, and contact details.
- `research/index.html`: paper descriptions and abstracts.
- `contact/index.html`: contact details and CV.
- `files/Daolin_Bai_CV.pdf`: academic CV.
- `assets/`: photograph, styles, scripts, and locally hosted Lora fonts.

“Revising the Separation: Optimal Monetary-Fiscal Mix in Open Economy” is the Job Market Paper. Both papers are marked “Draft coming soon.” Paper PDFs are intentionally excluded from this repository.

## Local preview

Run `python3 -m http.server 8765` from this directory and open http://localhost:8765/.

## Hosting

Publish the `main` branch root with GitHub Pages. The `.nojekyll` file keeps this buildless site unchanged. No package installation or build command is required.
